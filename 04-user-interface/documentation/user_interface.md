# User Interface and Accessibility

## Aquarium Care Agent Dashboard

The Aquarium Care Agent will provide a simple and accessible dashboard
for monitoring aquarium conditions.

The dashboard will display current water-quality parameters, aquarium
health risk, alerts, and actionable recommendations.

## 1. Dashboard Components

The dashboard will contain the following components:

1. Aquarium Status
2. Water-Quality Monitoring
3. Health-Risk Prediction
4. Alerts and Notifications
5. Actionable Recommendations

The interface will provide a clear view of the aquarium's current condition
and help the aquarium owner understand when corrective action is required.

## 2. Real-Time Monitoring

The dashboard will display the latest readings received from the aquarium
monitoring system.

The monitored parameters include:

- pH
- Temperature
- Dissolved Oxygen
- Ammonia
- Water Level

The readings will be presented using clear values, status indicators,
and visual elements so that abnormal conditions can be identified quickly.

## 3. Alerts and Notifications

The system will generate alerts when monitored conditions become abnormal
or when the predicted aquarium health risk becomes high.

Alerts will be classified according to severity:

- Low: Continue monitoring.
- Medium: Attention and corrective action required.
- High: Immediate attention required.

## 4. Accessibility and Usability

The dashboard will use a simple and understandable design.

Accessibility features will include:

- Clear labels for every parameter.
- Simple language instead of complex technical terminology.
- Large and readable text.
- Consistent layout and navigation.
- Status indicators using both colour and text.
- Clear warning and alert messages.
- Recommendations written as simple actions.
- Important information placed prominently on the dashboard.

## 5. User Interaction Flow

The user interaction flow is:

Real-Time Aquarium Data
        ↓
Dashboard
        ↓
Health Status and Risk
        ↓
Alert if Required
        ↓
Actionable Recommendation
        ↓
Aquarium Owner

The interface is designed to help the aquarium owner understand the
aquarium condition and take appropriate action without requiring
advanced technical knowledge.
